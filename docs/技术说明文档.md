## 一、系统概述

**SIFF Film-Person Match System（SIFF 排班助手）** 是面向上海国际电影节字幕组排班工作的纯前端 Web 应用。系统将两类 Excel 源数据——**电影排片表**与**字幕员时间表**——整合为可编辑、可自动分配、可导出的**排班总表**，实现「每一场电影 → 两名字幕员」的完整排班闭环。

### 1.1 核心特性

| 能力 | 说明 |
|------|------|
| Excel 导入 | 浏览器端解析排片表与字幕员问卷，无需后端 |
| 手动排班 | 下拉选择、拖拽分配、撤回上一步 |
| 自动排班 | 按行政区优先级与全局约束批量填充，保留已有手动分配 |
| 搭档管理 | Excel 搭档 + 界面手动覆盖，双向绑定校验 |
| 数据持久化 | 全部状态保存在 `localStorage`，刷新不丢失 |
| Excel 导出 | 按日期分 Sheet 导出最终排班总表 |

### 1.2 技术栈

| 类别 | 选型 |
|------|------|
| 框架 | React 18 + TypeScript |
| 构建 | Vite 7 |
| 路由 | React Router 7 |
| 样式 | Tailwind CSS |
| Excel | SheetJS (`xlsx`) |
| 拖拽 | react-dnd（排班编辑日历视图） |
| 排序 | @dnd-kit（设置页行政区列表） |
| 动画 | Framer Motion |
| 校验 | Zod（设置页表单） |
| 通知 | Sonner |

**架构特点**：无后端、无数据库、无 Docker；所有计算与存储均在浏览器完成。

### 1.3 标准模板文件

内置模板位于 `public/templates/`（构建后对应 `/templates/...`）：

| 文件 | 用途 |
|------|------|
| `后五天问卷调查 给静静.xlsx` | 字幕员姓名、负责区域、搭档、各日各时段可用性 |
| `2024排片表.xlsx` | 电影节各影院、影厅、时间段的排片信息 |

原始源文件同时保留在 `assets/` 目录。仪表盘上的「下载模板」按钮当前显示「开发中」提示；可直接通过浏览器访问 `/templates/文件名.xlsx` 获取模板。

## 三、系统架构

### 3.1 路由

| 路径 | 页面组件 | 功能 |
|------|----------|------|
| `/` | `Dashboard` | 数据导入、流程导航 |
| `/schedule-table` | `ScheduleTable` | 只读查看排片表 |
| `/subtitler` | `SubtitlerSchedule` | 字幕员可用性、搭档编辑 |
| `/schedule` | `Schedule` | 日历/矩阵视图分配字幕员 |
| `/schedule-overview` | `ScheduleOverview` | 主编辑页、自动排班、搜索、导出 |
| `/settings` | `Settings` | 行政区优先级、排班约束 |

入口：`src/App.tsx`，布局由 `Navigation` + `Header` + 各页面 `main` 组成。

### 3.2 Context 数据层

```
SubtitlerProvider       →  ParsedSchedule（字幕员原始数据 + 手动搭档覆盖）
ScheduleTableProvider   →  ParsedScheduleTable（排片原始数据）
ScheduleProvider        →  ScheduleTable（排班总表：cells + assignments）
```

Provider 嵌套顺序：`SubtitlerProvider` → `ScheduleTableProvider` → `ScheduleProvider`。

`useScheduleTableSync` Hook 在排班相关页面挂载，监听排片数据变化并调用 `syncFromParsedData` 合并总表 cells，同时尽量保留已有 assignments。

### 3.3 页面与总表读写关系

| 页面 | 读总表 | 写总表 | 说明 |
|------|--------|--------|------|
| 仪表盘 | 否 | 间接 | 上传排片表触发 cells 重建 |
| 电影排片 | 否 | 否 | 只读参照 |
| 字幕员表 | 是（搭档日志） | 否（搭档覆盖存 SubtitlerContext） | 约束数据源 |
| 排班编辑 | 是 | 是 | 日历/矩阵写入 assignments |
| 排班总表 | 是 | 是 | 主编辑 + 自动排班 + 导出 |
| 设置 | 否 | 间接 | 约束影响自动排班 |

## 四、核心数据模型

### 4.1 排片表 `ParsedScheduleTable`

- **解析**：`src/lib/parseScheduleTable.ts`
- **Context**：`src/contexts/ScheduleTableContext.tsx`
- **字段**：`dates`, `cinemas`, `halls`, `timeSlots`, `rows[]`
- **表头识别**：前 10 行内查找含「日期」「影院」「影厅」的行；第 5 列起解析 `HH:MM` 时间段列
- **影片行**：`rows[]` 含 `date`, `weekDay`, `cinema`, `hall`, `shows: Record<timeSlot, MovieShow>`
- **localStorage**：`schedule_table_data_v2`、`schedule_table_file_name`

排片时间段由 Excel 表头动态解析，常见档包括 08:30、09:30、10:00、10:30、12:00、12:30、13:00、13:30、14:30、15:00、15:30、18:00、18:30、20:40、21:00 等。

### 4.2 字幕员表 `ParsedSchedule`

- **解析**：`src/lib/parseSubtitlerExcel.ts`
- **Context**：`src/contexts/SubtitlerContext.tsx`
- **字段**：`rows[]`（`id`, `name`, `schedule`, `districts`, `partner`）、`dates[]`、`headers`
- **表头格式**：支持 `18日-9:00`、`6月18日 9:00` 等组合列名
- **格子语义**（重要）：
  - **填了内容**（时间等）→ `有空`，界面显示绿色，**可分配**
  - **空白** → `没空`，不可分配
- **区域列**：对应 11 个上海行政区简称，填 `1` 表示负责该区域
- **localStorage**：`subtitler_data_v2`、`subtitler_file_name`

标准字幕员时间段（`SUBTITLER_TIME_SLOTS`）：`9:00`, `10:30`, `13:00`, `15:00`, `18:00`, `20:40`, `23:00`。2026 前五天问卷常用其中 5～6 档。

### 4.3 排班总表 `ScheduleTable`

```typescript
interface ScheduleTable {
  cells: ScheduleCell[];
  assignments: Record<string, ScheduleAssignment>;
  assignmentSources?: Record<string, 'manual' | 'auto'>;
}

// key = `${date}|${cinema}|${hall}|${timeSlot}`
interface ScheduleAssignment {
  subtitler1: string | null;
  subtitler2: string | null;
  subtitler1Id: string | null;
  subtitler2Id: string | null;
}
```

- **构建**：`buildScheduleTableFromParsedData()` — 从排片表生成 cells（仅有电影的场次）
- **合并**：`syncScheduleTableWithParsedData()` — 排片更新时保留已有 assignments
- **撤回**：`ScheduleContext` 维护最多 50 步 undo 栈
- **localStorage**：`schedule_table_assignments_v2`、`schedule_mode`、`schedule_undo_stack_v1`

### 4.4 手动搭档覆盖 `ManualPartnerOverrides`

- **模块**：`src/lib/partnerOverrides.ts`
- **键**：`manual_partner_overrides_v1`
- **规则**：界面修改搭档后双向写入；仅**双向绑定**的搭档对在自动排班时强制同场出现
- **优先级**：手动覆盖 > Excel 原始搭档列

## 五、时间与区域映射

### 5.1 影片时间 → 字幕员时间 `TIME_MAPPING`

定义于 `src/lib/scheduleConstants.ts`，核心映射：

| 字幕员档 | 对应影片时间 |
|----------|--------------|
| 10:30 | 10:00, 10:30 |
| 13:00 | 12:00, 12:30, 13:00, 13:30 |
| 15:00 | 14:30, 15:00, 15:30 |
| 18:00 | 18:00, 18:30 |
| 20:40 | 20:40, 21:00 |

`getSubtitlerTimeSlot()`（`scheduleHelpers.ts`）额外处理边界：

1. 精确匹配 `TIME_MAPPING`
2. 早于最早档 → 归入最早档
3. 晚于最晚档 → 归入最晚档
4. 中间值 → 取不晚于影片时间的最近字幕员档

### 5.2 日期格式转换

排片表日期：`2026-06-18`（ISO）  
字幕员表日期：`18日`  
转换函数：`convertToSubtitlerDate()`（`scheduleHelpers.ts`）

### 5.3 影院 → 行政区 `CINEMA_DISTRICTS`

`scheduleConstants.ts` 维护 2026 排片表影院全称到 11 个行政区的映射。`getCinemaDistrict()` 支持精确匹配与包含关系模糊匹配；未识别影院在界面与导出中以灰色标记，自动排班会跳过并记录原因。

## 六、数据同步机制

| 触发 | 行为 |
|------|------|
| 上传排片表 | `setScheduleData` → 各页 `useScheduleTableSync` → `syncFromParsedData` 合并 cells |
| 上传字幕员表 | `setSubtitlerData`；不改变总表结构，影响下拉可选人与自动排班候选 |
| `updateAssignment` | 更新 assignments、`assignmentSources`，写入 localStorage，可选入 undo 栈 |
| 手动修改搭档 | `setManualPartner` → 持久化 `manual_partner_overrides_v1` |
| 清除分配 | `clearAllAssignments` 清空 assignments 与 sources |

## 七、自动排班算法

**入口**：排班总表 / 排班编辑 → 自动排班模式 →「执行自动排班」  
**实现**：`src/lib/autoSchedule.ts`  
**Hook**：`src/hooks/useAutoSchedule.ts`

### 7.1 流程概要

1. 读取 `settings_constraints`、`settings_districts`
2. 构建 `manualAssignments`：已有 **手动** 分配（含 source 为 `manual` 或未标记 source 的场次）予以保留
3. 初始化每位字幕员状态：日场次、总场次、已用时段、同日锁定影院
4. 按行政区优先级逐区处理未分配场次
5. 每场：映射时间 → 识别影院区域 → 筛选负责该区域且问卷标记有空的字幕员 → 应用约束 → 优先搭档配对 → 写入 subtitler1/2
6. 生成 `AutoScheduleReport`（成功数、失败明细、搭档去向日志）

### 7.2 默认约束 `DEFAULT_CONSTRAINTS`

| 项 | 默认值 | 说明 |
|----|--------|------|
| `maxPerDay` | 2 | 每人每天最多场数 |
| `maxTotal` | 5 | 每人全程最多场数 |
| `exclusiveTimeSlot` | true | 同一字幕员同一时段只能去一个厅 |
| `noCrossCinemaPerDay` | false | 同日禁止跨影院（可跨影厅） |
| `preferMoreTimeSlots` | true | 优先问卷剩余时段**多**的字幕员 |
| `preferFewerTimeSlots` | false | 与上项互斥；均关闭则随机排序 |

### 7.3 搭档规则

- 有双向搭档者：**必须与搭档同场**；搭档不可用则本人也不作为独立候选
- 无搭档或单向绑定：按普通候选处理；单向绑定会产出警告

### 7.4 跳过原因码

| 原因码 | 含义 |
|--------|------|
| `time_unmapped` | 影片时间无法映射到字幕员时段 |
| `cinema_unknown` | 影院未识别所属行政区 |
| `no_district_staff` | 该区域无负责字幕员或全员不可用 |
| `slot_unavailable` | 该时段无满足约束的空闲字幕员 |
| `only_one_available` | 仅找到一名可用字幕员 |
| `partner_unavailable` | 搭档不可用或未双向绑定 |

报告面板：`AutoScheduleReportPanel`；搭档汇总：`PartnerAssignmentLogPanel` + `buildPartnerLogs.ts`。

## 八、手动排班与可用性查询

`getAvailableSubtitlers()`（`scheduleHelpers.ts`）返回下拉候选，条件包括：

1. 问卷对应日期+时段标记为有空（绿色格）
2. 未被同场另一字幕员占用
3. 手动模式下**不**强制应用 maxPerDay/maxTotal（约束主要作用于自动排班）

排班编辑页支持 react-dnd 拖拽：将左侧字幕员拖到场次卡片 → 填入字幕员1。

## 九、导出

排班总表页「导出 Excel」：

- 文件名：`排班总表_YYYYMMDD.xlsx`
- 每个 festival 日期一个 Sheet
- 列：影院 | 影厅 | 日期 | 星期 | 时间 | 电影 | 字幕员1 | 字幕员2
- 已识别区域影院在前，未识别区域在后；未知区域行标灰

设置页的「导出设置」目前仅持久化到 localStorage，**尚未接入**导出逻辑。
