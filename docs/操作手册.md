## 1. 快速开始

1. 浏览器打开 **[https://siff-f-pmatch.vercel.app/](https://siff-f-pmatch.vercel.app/)**
2. 下载并填写两份 Excel 模板（见 [§3 准备 Excel 数据](#3-准备-excel-数据)）
3. 在仪表盘上传字幕员表与排片表
4. 进入排班总表，执行自动排班并手动补全
5. 导出 `排班总表_YYYYMMDD.xlsx`

推荐流程：

```
打开在线地址 → 下载模板 → 填写 Excel → 上传两份数据 → 设置规则 → 自动/手动排班 → 导出 Excel
```

左侧导航栏六个入口：


| 菜单   | 作用                       |
| ---- | ------------------------ |
| 仪表盘  | 上传数据、查看流程                |
| 排班编辑 | 全局日历/矩阵分配，支持拖拽           |
| 字幕员表 | 查看人员可用性、修改搭档             |
| 电影排片 | 查看排片结构（只读）               |
| 排班总表 | **主编辑 + 搜索 + 自动排班 + 导出** |
| 设置   | 行政区优先级、排班约束              |


**数据关系**：必须先上传**电影排片表**才能生成场次；字幕员表决定每场可选哪些人。排班编辑与排班总表操作同一份数据，实时同步。

## 2. 访问应用

### 2.1 在线版（推荐，字幕组日常使用）

直接访问：**[https://siff-f-pmatch.vercel.app/](https://siff-f-pmatch.vercel.app/)**

- 部署在 Vercel，打开即用，适合排班操作员
- 数据保存在**当前浏览器**的 localStorage 中
- 换电脑、换浏览器或清除网站数据后，需重新上传 Excel
- 排班完成后务必**导出 Excel** 备份

### 2.2 本地开发（技术人员）

源码仓库：[https://github.com/cassini123/SIFF-FPmatch](https://github.com/cassini123/SIFF-FPmatch)

```bash
git clone https://github.com/cassini123/SIFF-FPmatch.git
cd SIFF-FPmatch
pnpm install
pnpm run dev
```

浏览器打开 **http://localhost:5001**（开发端口见 `scripts/dev.sh`）。

### 2.3 离线静态包

项目内 `dist-package/` 目录提供预构建包，运行 `start.sh`（Mac/Linux）或 `start.bat`（Windows）后访问 **http://localhost:5000**。

系统内置两份标准模板。在线版可直接点击下列链接下载（域名与线上一致）：

| 模板 | 在线下载链接 |

| 电影排片表 | [2024排片表.xlsx](https://siff-f-pmatch.vercel.app/templates/2024%E6%8E%92%E7%89%87%E8%A1%A8.xlsx) |

相对路径（任意部署域名后均可使用）：

| 模板 | 路径 |
|------|------|
| 字幕员问卷 | `/templates/后五天问卷调查 给静静.xlsx` |
| 电影排片表 | `/templates/2024排片表.xlsx` |

> 仪表盘底部的「下载字幕员模板」「下载排片表模板」按钮目前显示「开发中」。请使用上表链接下载，或从 [GitHub 仓库](https://github.com/cassini123/SIFF-FPmatch) 的 `public/templates/` 目录获取。

### 3.1 字幕员问卷填写要点


| 列/区域   | 填写说明                       |
| ------ | -------------------------- |
| 姓名     | 字幕员真实姓名，与排班下拉一致            |
| 区域     | 11 个上海行政区，负责哪个区填 `1`       |
| 搭档     | 固定搭档姓名；可在系统内后续修改           |
| 日期-时段列 | 表头如 `18日-9:00`、`18日-10:30` |


**可用性规则（重要）**：

- **格子内填了内容**（如具体时间）→ 表示**有空**，系统显示绿色，可被排班
- **格子留空** → 表示**没空**，不会被分配

### 3.2 排片表填写要点


| 列    | 填写说明                         |
| ---- | ---------------------------- |
| 日期   | 如 `2026-06-18`，支持 Excel 日期格式 |
| 周    | 星期                           |
| 影院   | 须与系统影院映射表一致（全称）              |
| 影厅   | 影厅编号或名称                      |
| 时间段列 | 表头为 `HH:MM`，单元格填电影信息         |


有电影内容的格子 = 需要分配 2 名字幕员的场次。

## 4. 上传数据

打开 **[https://siff-f-pmatch.vercel.app/](https://siff-f-pmatch.vercel.app/)** 首页（仪表盘）。

### 4.1 上传字幕员数据

1. 在「数据导入」卡片中，点击 **「字幕员数据」** 标签（默认选中）
2. 将填好的字幕员 Excel **拖入虚线框**，或点击选择文件
3. 解析成功后，底部显示绿色 ✓ 及文件名
4. 弹出提示时可选择跳转到「字幕员表」查看

### 4.2 上传电影排片表

1. 点击 **「电影排片表」** 标签
2. 上传排片 Excel
3. 解析成功后显示影院数、天数
4. 可选择跳转到「电影排片」查看

### 4.3 上传对总表的影响


| 上传内容 | 总表变化                         |
| ---- | ---------------------------- |
| 排片表  | 重建所有 **cells**（场次行）；已有分配尽量保留 |
| 字幕员表 | 不改变总表结构；影响下拉可选人与自动排班         |


若解析失败，请检查表头是否与模板一致（排片表须含「日期」「影院」「影厅」；字幕员表须含「姓名」及 `18日-9:00` 类列名）。

## 5. 核对电影排片

进入 **电影排片** 页面。


| 区域     | 操作                |
| ------ | ----------------- |
| 顶部日期标签 | 点击切换日期            |
| 左侧影院列表 | 点击选择影院            |
| 右侧表格   | 查看 影厅 × 时间段 的电影信息 |
| 底部统计   | 影院数、场次数           |


本页**只读**，不能直接改排班。表格中有电影内容的格子 = 排班总表中对应场次需分配 2 人。

如需更新排片，返回仪表盘重新上传排片表。

## 6. 核对字幕员可用性

进入 **字幕员表** 页面。


| 区域        | 操作                              |
| --------- | ------------------------------- |
| 姓名搜索 + 定位 | 输入姓名后回车或点「定位」，高亮并滚动到对应行         |
| 顶部日期标签    | 切换 18日、19日… 查看不同日期              |
| 区域列       | 绿色 `1` = 负责该区域                  |
| 时段列       | **绿色** = 有空；空白 = 没空             |
| 搭档列       | 下拉可修改搭档；金色边框 = 手动修改；靛蓝行 = 已双向绑定 |
| 搭档去向      | 查看各搭档对被分配到哪些场次                  |


### 6.1 修改搭档

1. 在「搭档」列下拉选择其他字幕员或「无」
2. 系统自动双向绑定（A 选 B，则 B 的搭档也为 A）
3. 手动修改优先级高于 Excel 原始数据，刷新后仍保留

**注意**：仅**双向绑定**的搭档在自动排班时会强制同场出现；单向填写会收到警告。

## 7. 配置排班规则（可选）

进入 **设置** 页面，修改后点击 **保存设置**。

### 7.1 行政区优先级

- 拖动列表调整 11 个区的顺序
- 越靠前，自动排班时越先处理该区域的场次
- 可点击「重置」恢复默认顺序

### 7.2 排班大前提条件


| 设置项        | 默认值    | 说明                     |
| ---------- | ------ | ---------------------- |
| 每天排班限制     | 2 场/天  | 自动排班生效                 |
| 总场次限制      | 5 场/总计 | 自动排班生效                 |
| 同一时间段互斥    | 开启     | 同一人同时只能去一个厅            |
| 同日禁止跨影院    | 关闭     | 开启后同一人同一天只能在一家影院（可跨影厅） |
| 优先时间块多的字幕员 | 开启     | 与「优先少」二选一；均关则随机        |
| 优先时间块少的字幕员 | 关闭     | 适合想把剩余时段少的人先排满         |


> 以上约束主要影响**自动排班**。手动下拉选择时不强制拦截日/总上限。

### 7.3 其他设置

「小语种特殊规则」「导出设置」可填写保存，当前版本尚未接入排班与导出逻辑，可忽略。

## 8. 排班编辑（日历/矩阵）

进入 **排班编辑** 页面。适合全局浏览与批量操作。

### 8.1 工具栏


| 按钮             | 功能                |
| -------------- | ----------------- |
| 切换至矩阵视图 / 日历视图 | 两种布局互换            |
| 撤回上一步          | 撤销最近一次手动分配（仅手动模式） |
| 手动排班 / 自动排班    | 模式切换              |
| 执行自动排班         | 自动模式下批量填充         |
| 清除分配           | 清空所有已分配字幕员（需确认）   |
| 进度             | 共 N 场 · 已完成 M 场   |


### 8.2 日历视图

- **左侧**：字幕员列表，可 **拖拽** 到右侧场次卡片 → 填入字幕员1
- **右侧**：按日期分组的场次卡片
- 每场有两个下拉：**字幕员1**、**字幕员2**
- 双人填完 → 卡片变绿；冲突 → 变红

### 8.3 矩阵视图

表格列：日期/时间 | 影片 | 字幕员1 | 字幕员2，适合逐行批量操作。

自动排班完成后会显示报告面板，列出未配齐场次及原因。

## 9. 排班总表（主工作区）

进入 **排班总表** — 最终核对与导出的主界面。

### 9.1 头部操作


| 控件       | 说明                   |
| -------- | -------------------- |
| 电影搜索     | 按片名或编号搜索，点击结果跳转到对应场次 |
| 字幕员搜索    | 按姓名搜索已分配场次           |
| 搭档去向     | 查看搭档对被分配到的场次列表       |
| 手动排班     | 表格内出现可编辑下拉           |
| 自动排班     | 只读表格 + 显示「执行自动排班」    |
| 清除       | 自动模式下清空所有分配（需确认）     |
| 导出 Excel | 下载完整排班结果             |
| 执行自动排班   | 按规则批量填充，**保留已有手动分配** |


头部显示当前影院、日期及进度：**已分配 X / Y 场**。

### 9.2 左侧边栏


| 标签  | 功能                        |
| --- | ------------------------- |
| 影院  | 选择当前查看的影院；未识别区域影院显示在底部灰色区 |
| 字幕员 | 选择某字幕员，上方显示其已分配场次列表       |


### 9.3 主体表格


| 列    | 可编辑     | 说明   |
| ---- | ------- | ---- |
| 影厅   | 否       | —    |
| 时间   | 否       | —    |
| 电影   | 否       | —    |
| 字幕员1 | 是（手动模式） | 蓝色标识 |
| 字幕员2 | 是（手动模式） | 绿色标识 |


- 顶部日期标签切换日期
- 分配完成行显示绿色背景
- 底部提示：下拉只显示此时段有空且未被占用的字幕员

### 9.4 推荐操作顺序

1. 确认排片表、字幕员表均已上传
2. （可选）在设置页调整行政区顺序与约束
3. （可选）在字幕员表修正搭档关系
4. 切换 **自动排班** → 点击 **执行自动排班**
5. 阅读自动排班报告，了解未配齐原因
6. 切换 **手动排班** → 按影院/日期补全剩余场次
7. 使用搜索与「搭档去向」做交叉核对
8. 进度达到 100% 后 → **导出 Excel**

## 10. 导出结果

在排班总表页点击 **「导出 Excel」**：

- 文件名：`排班总表_YYYYMMDD.xlsx`
- 每个 festival 日期一个 Sheet
- 列：影院 | 影厅 | 日期 | 星期 | 时间 | 电影 | 字幕员1 | 字幕员2
- 未识别区域的影院行以灰色标记

导出文件即为可交付的最终排班总表。

## 11. 常见问题

### Q：模板怎么下载？

在线版直接打开：

- [字幕员问卷模板](https://siff-f-pmatch.vercel.app/templates/%E5%90%8E%E4%BA%94%E5%A4%A9%E9%97%AE%E5%8D%B7%E8%B0%83%E6%9F%A5%20%E7%BB%99%E9%9D%99%E9%9D%99.xlsx)
- [排片表模板](https://siff-f-pmatch.vercel.app/templates/2024%E6%8E%92%E7%89%87%E8%A1%A8.xlsx)

也可见 [§3 准备 Excel 数据](#3-准备-excel-数据)。仪表盘内下载按钮暂未启用。

### Q：在线版和本地版有什么区别？

功能相同。在线版（Vercel）免安装、打开链接即用；本地版适合开发或内网离线环境。两者数据均存在浏览器 localStorage，**不跨设备同步**。

### Q：发现问题或需要功能改进？

到 GitHub 仓库提 Issue：[https://github.com/cassini123/SIFF-FPmatch/issues](https://github.com/cassini123/SIFF-FPmatch/issues)

### Q：上传后排班总表是空的？

需先上传 **电影排片表**，系统才能生成场次。仅上传字幕员表不会产生场次行。

### Q：下拉显示「此时段无空闲字幕员」？

1. 到字幕员表确认该日期、时段是否为**绿色**（有空）
2. 确认该人是否已被同场另一字幕员选中
3. 确认是否已上传字幕员数据
4. 注意：问卷中**空白格表示没空**，与早期文档描述相反

### Q：自动排班后很多场次未配齐？

查看自动排班报告中的原因统计，常见情况：


| 原因        | 处理建议               |
| --------- | ------------------ |
| 影院未识别区域   | 检查排片表影院名称是否与系统映射一致 |
| 该区域无负责字幕员 | 在问卷区域列补填 `1`       |
| 该时段无空闲字幕员 | 在问卷对应格填写可用时间       |
| 搭档不可用     | 修正搭档关系或改手动分配       |
| 影片时间无法映射  | 检查排片时间段是否在支持范围内    |


### Q：排班编辑和排班总表有什么区别？


| 页面   | 特点                   |
| ---- | -------------------- |
| 排班编辑 | 全局日历/矩阵、拖拽、撤回；适合宏观分配 |
| 排班总表 | 按影院逐日核对、搜索、导出；适合终审   |


两者操作同一份数据，修改即时同步。

### Q：手动排了的内容会被自动排班覆盖吗？

不会。已有**手动分配**的场次在自动排班时会被保留；自动排班只填充空白或此前由自动模式写入且未被手动改动的场次。

### Q：刷新页面数据会丢吗？

不会。数据保存在浏览器 localStorage。清除浏览器网站数据/缓存会导致丢失，重要结果请及时导出 Excel。

### Q：换电脑如何继续？

在新电脑浏览器中重新上传两份 Excel。localStorage 不跨设备同步。若需迁移，可导出排班 Excel 作为归档；源 Excel 文件本身即为可重新导入的「备份」。
